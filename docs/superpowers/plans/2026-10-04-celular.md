# Celular Integration Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

## Goal

Bring the standalone Celular Paper plugin (package `dev.linqfy.celular`, built and playtested separately) into
BigCasares as the `celular` module, reusing BigCasares' module lifecycle and Java resource pack instead of the
standalone plugin's own main class and HTTP pack server.

## Tech Stack

- Paper API 26.2.build.56-alpha, Java 25, Gradle 9.2.1.
- Unit tests: JUnit 5 against `spigot-api:26.2-R0.1-SNAPSHOT`.
- Asset generators: Python 3 + Pillow + NumPy, ffmpeg for the videos (`tools/celular/`).

## File Structure

New:
- `src/main/java/dev/linqfy/bigCasares/modules/celular/*.java`: 11 classes (see the design spec).
- `src/test/java/dev/linqfy/bigCasares/modules/celular/*Test.java`: 6 test classes.
- `src/main/resources/celular/videos.yml`: bundled video list (generated).
- `resourcepack/java/assets/celular/`: item definitions, models and textures (generated).
- `tools/celular/`: `generar_celular.py`, `convertir_videos.py` and previews.
- `docs/superpowers/specs/2026-10-04-celular-design.md` and this plan.

Modified:
- `BigCasares.java`: construct, register and expose `CelularModule`.
- `config.yml`: `modules.celular.enabled: true` and the `celular:` section.
- `plugin.yml`: `/celular` command (alias `/celu`) and `bigcasares.celular.admin` (also a child of `bigcasares.*`).
- `.gitignore`: `tools/celular/videos/` (source videos are not committed).

## Boundaries

- No changes to other modules or to `build.gradle`.
- No changes to the BigCasares resource-pack or Geyser module code.

### Deviations from plan
- Developed and playtested as a standalone plugin first, then integrated.
- No `CelularStorage`: the only persistent state is the per-village flag, stored in the village's own
  `GeneratedStructure` persistent data container, and the video index stored on each item.
- The village loot was verified on the standalone plugin (desert village: first chest got the phone, second did not);
  the BigCasares build was verified with `clean build` but not started on a live server.

### Known limitations
- Videos are silent and do not restart when switched (client-side animated textures).
- ~170 MB of client texture memory for the bundled videos; the Java pack grows by ~28 MB, and the current jar packaging
  bundles the pack several times (jar ~88 MB).
- Bedrock players see a clock.
- Source videos are not committed (`tools/celular/videos/` is ignored).
