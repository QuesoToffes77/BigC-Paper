## Discrepancies and remaining work

| Finding | Evidence and implication |
| --- | --- |
| Old stack and reproducibility claims | Former guidelines said Spigot 1.21.11/Java 21. `build.gradle` uses Paper `26.2.build.56-alpha`/Java 25. Wrapper is 9.2.1; run-paper only fixes Minecraft 26.2, not a server build. SNAPSHOT dependencies and absent locks/checksum prevent a fully reproducible-resolution claim. No upgrades applied. |
| Startup prerequisites omitted | `plugin.yml` hard-depends on BetterModel. Mission/Bounty/Shop economy gateways throw without Vault/provider; `ModuleManager` unwinds failed startup and bootstrap fails. `runServer` does not install these plugins. |
| Configuration switches and module independence | Manager accepts nested/flat switches and legacy shop alias; absent keys default to enabled. Five IDs lack explicit shipped switches: `danger-system`, `death-tombstone-system`, `special-items`, `warp-system`, `mob-scaling`. Consider explicit defaults in a behavior-reviewed follow-up. Modules have bootstrap-wired dependencies; package names/settings prefixes differ from IDs. |
| Full reload is not transactional restoration | `ReloadCoordinator` disables the old runtime before loading a candidate. Scopes coexist with plugin-wide cleanup. Do not claim old-runtime rollback or completion of the global-cleanup migration. |
| Pack and item upgrades preserve local sources | `RuntimePackSourceSeeder`/`ItemCatalogSeeder` copy missing files. Runtime reads `content/pack`/`content/items`, not the checkout. `ResourcePackModule` publishes BigCasares and BetterModel as a stack; the old merge property was unused. BetterModel reload precedes the content-pack transaction. Geyser extracts the packaged MCPACK; targeted pack reload does not register an updated Bedrock pack. |
| Model/animation gaps | Nexus/Abyss Guardian `.bbmodel` sources are not packaged and need separate deployment. The installer overwrites differing packaged Sahur/Ballesta/toxic model copies. Boss/Nexus teardown does not await death/destroyed clips; Bedrock phase/cast notifications store names without transmitting controller state. No player-limb service is implemented. |
| Ability schema exceeds runtime behavior | Some effect enums fall through generic dispatch; telegraph renderer uses a common circle/sound, `RANDOM_POSITION` selects a player UUID, and `ALL_IN_RADIUS` ignores `max-targets`. Skills now distinguish accepted YAML from implemented effects. Future runtime changes need behavioral tests. |
| Deployment-specific defaults | Pack HTTP defaults advertise/bind loopback; remote clients need a reachable URL plus listener/proxy. End event defaults to the historical 2026-07-25 date. Review deployment choices; this audit did not invent new defaults or event dates. |
| Historical contradictions | Plans retain older Java/API versions, superseded reload status, evolving nuke counts, Acid Rain destruction defaults, grappling ranges and nitric-acid scope. PR #11 mixes damage points/hearts. Index caveats prevent using these as current contracts; provenance retained. |
| Workflow gaps | CI checks Java/packs but not Node tests/Python generators. Wrapper is tracked non-executable. `clean` removes the local server beneath `build/`. Root npm manifests only provision Codex. Consider a separate persistent test-server location and targeted tool CI when those workflows change. |
| Client host guard | `tools/minecraft-test-client/lib/config.mjs` accepts any string beginning `127.` without DNS/address validation. The README now describes the lexical check; strict loopback validation is a separate code change. |
